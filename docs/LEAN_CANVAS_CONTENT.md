# Lean Canvas Content

## Problem
- Students struggle to identify suitable career roles from their current skills.
- Students do not know which skills are missing for a target role.
- Career and learning choices are often generic rather than personalized.

## Solution
- AI-based career recommendation.
- Skill-gap analysis.
- Personalized learning roadmap.
- Sample job-role matching.
- Resume keyword analysis.

## Unique Value Proposition
"One student profile, one AI-assisted career path: discover suitable roles, missing skills, and the next learning steps."

## Unfair Advantage
- Transparent skill-to-role matching.
- Combines career recommendation, skill-gap analysis and learning roadmap in one prototype.

## Customer Segments
- College students.
- Fresh graduates.
- Entry-level job seekers.

## Early Adopters
- Final-year engineering students.
- Students preparing for placements.

## Channels
- College placement cells.
- Student communities.
- Career workshops.
- Web application.

## Key Metrics
- Career recommendation relevance.
- Skill-gap coverage.
- Resume skill detection.
- Number of completed recommendations.

## Cost Structure
- Development time.
- Hosting/infrastructure if deployed.
- Dataset preparation and maintenance.

## Revenue Streams
- Freemium career assessment.
- Institutional licensing.
- Premium resume/roadmap features.

## Existing Alternatives
- Generic job portals.
- Static career websites.
- Manual career counseling.
